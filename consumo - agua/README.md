
# 💧 Consumo de Água

## 📌 Sobre o projeto

Este projeto foi desenvolvido em Python para analisar o consumo mensal de água de diferentes tipos de imóveis.

O programa recebe o tipo de imóvel e o consumo em m³ e, de acordo com essas informações, apresenta uma mensagem de orientação ao usuário.

## 🎯 Objetivo

O objetivo é conscientizar sobre o consumo de água e identificar situações de consumo econômico, moderado ou excessivo.

## 🐍 Linguagem utilizada

- Python

## ⚙️ Como funciona

O usuário informa:

- Tipo do imóvel: comercial, casa ou apartamento.
- Consumo mensal de água em m³.

Após receber os dados, o programa verifica as condições e apresenta o resultado correspondente.

## ▶️ Como executar

1. Abra o arquivo app.py.
2. Execute o programa pelo Python.
3. Informe o tipo do imóvel.
4. Informe o consumo mensal em m³.
5. Veja a mensagem apresentada.

## 📂 Arquivos do projeto

- app.py — contém o código principal do programa.
- README.md — apresenta as informações sobre o projeto.
